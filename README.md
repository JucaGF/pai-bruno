# Pai Bruno · Yellowar

Homenagem do círculo Yellowar para o Pai Bruno, celebrando o encontro do EJC São Pedro Pescador em 11 de julho de 2025.

## Como visualizar

Na pasta do projeto, inicie um servidor local:

```bash
python3 -m http.server 4173
```

Depois acesse [http://localhost:4173](http://localhost:4173). O servidor local é o jeito recomendado de testar a trilha sonora; a reprodução começa quando a pessoa aperta um dos botões de áudio.

## Estrutura

- `index.html` contém a carta, a narrativa, a galeria e os controles acessíveis.
- `styles.css` contém a identidade amarela, a colagem e o layout responsivo.
- `script.js` controla a trilha, os efeitos de entrada e a galeria ampliada.
- `assets/` contém cópias estáveis das fotos, cartaz, logo e áudio usados na página.

Os arquivos originais permanecem nas pastas `fotos e vídeos/` e `música do encontro/`.
